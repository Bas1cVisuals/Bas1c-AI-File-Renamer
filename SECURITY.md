# Security Policy

## BAS1C AI Image Renamer

BAS1C AI Image Renamer is a locally operated Python application that uses Ollama vision models to analyze images and suggest descriptive filenames.

We take security and responsible vulnerability disclosure seriously.

## Supported Versions

Security updates will primarily be provided for the latest version of the project.

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | Not guaranteed |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

Please do not publicly disclose security vulnerabilities through GitHub Issues or Discussions.

Use GitHub's Private Vulnerability Reporting feature if it is enabled for this repository.

When submitting a report, please include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or component.
- The potential security impact.
- Relevant screenshots or logs, if available.

Do not include personal images, passwords, API keys, credentials, or other sensitive information in vulnerability reports.

## Security Considerations

Please follow these precautions when using BAS1C AI Image Renamer:

- Install Ollama and vision models only from trusted sources.
- Keep Python, Ollama, and project dependencies updated.
- Run the application with standard user permissions whenever possible.
- Only select files and folders you are authorized to access.
- Review suggested filenames before applying rename operations.
- Maintain backups of important files before performing bulk renaming.
- Avoid processing suspicious or potentially malicious files.
- Do not share generated reports publicly if they contain private file paths or other sensitive information.

## Privacy and Local Processing

BAS1C AI Image Renamer is designed to process images through a locally installed Ollama service.

However, local processing should not be interpreted as a guarantee that every component operates entirely offline.

Users are responsible for verifying their Ollama configuration, installed models, dependencies, and network activity.

## Scope of This Policy

This policy covers security vulnerabilities directly related to the BAS1C AI Image Renamer source code and its documented functionality.

Issues originating from third-party software, Python packages, Ollama, or the operating system should also be reported to their respective maintainers when appropriate.

## Responsible Disclosure

We appreciate responsible security research and encourage users to report vulnerabilities privately before making them public.

We will review submitted reports and work towards addressing valid security issues where possible.

Thank you for helping make BAS1C AI Image Renamer safer and more reliable.
